# Cubrim Research

Research questions, evaluation methods and the public development program for **Cubrim Archiver**, **Cubrim Addressor** and **Cubrim Web**.

Cubrim develops compression and address-based storage/transfer as commercial products. This knowledge collection is intended to share selected research and invite scientific discussion without distributing the proprietary engine, backend or platform implementation.

## Read

- [Public roadmap](ROADMAP.md): priorities and expected outcomes across all three products.
- [Research agenda](RESEARCH-AGENDA.md): questions about representation, compression limits, practical performance and shared information.
- [Evaluation methodology](METHODOLOGY.md): what a result must report to be interpretable and reproducible.
- [Contributing and publication](CONTRIBUTING.md): source attribution, review and information boundaries.

## Languages

The maintained repository entry points and engineering instructions are in English.
Public documents are also available in [Russian](docs/ru/OVERVIEW.md) and
[Simplified Chinese](docs/zh-CN/OVERVIEW.md). Translations preserve the same
scope, dates, units and limitations. They do not add performance or release claims.

## Publication record

[PUBLICATION.json](PUBLICATION.json) lists the exact published document set and
SHA-256 hashes. Public documentation is a curated export with its own history;
it is not a mirror of product source. Bibliographic metadata, reviewed articles
and measured reports can be added through the same review process. Full books,
private analyses and implementation details are outside this collection.

The public product website is [cubrim.com](https://cubrim.com/en/). Published results and experimental plans are separate: a roadmap does not establish performance or readiness. No new benchmark result is claimed by this initial collection.

## Scope

Include literature reviews, mathematical questions, reviewed methodology, rights-cleared data descriptions, approved measured summaries and articles. Exclude product code, unreleased implementation details, internal council transcripts, credentials, customer data and private negotiations. Shared science and proprietary implementation have different publication boundaries.

The first edition contains an agenda and methodology; an audited source catalogue and new scientific articles will be added through review. Public availability does not by itself grant an open-source license to Cubrim implementations. Reuse terms for contributed text/data must be explicitly recorded before publication; existing third-party rights are retained.
