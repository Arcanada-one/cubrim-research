# Agent instructions — Cubrim Research

This repository is a curated knowledge publication surface, not the source repository for Cubrim products. Read README.md, ROADMAP.md, RESEARCH-AGENDA.md, METHODOLOGY.md and CONTRIBUTING.md before changing it.

## Scope

Maintain English scientific documentation, primary-source records, approved research reports and the public roadmap. Do not import product implementation, internal council logs, private experiments, customer information, credentials, source archives, build caches or private git history. A content move is a publication decision, not just file organization.

## Research quality

Preserve source terminology and assumptions. Separate a source claim, an inference, a hypothesis, a simulated estimate and a measured result. Identify missing data. Every quantitative result names the workload, build/evaluation boundary, units and restoration checks. No universal compression/ranking claim follows from a bounded corpus. Retain corrections and supported negative results.

## Change and review

Make small reviewable changes. Add new documents to the index. Check links, references, units, attribution and rights. Review embedded/generated content, not just filenames. Sensitive or patent-relevant findings stay in the private project workflow until approved; do not use a public issue or PR to request review by pasting the confidential content.

The Cubrim collective has architecture and engineering roles, but public contributions do not confer production, credential, repository-administration or product-release authority. Do not expand permissions or spending, disable checks, change licensing, rewrite history or publish an unreviewed private export. Public-research review is separate from approval to release commercial binaries.

No agent process, scheduler or benchmark campaign is started by these instructions. Use the actual authorized runtime and task process; never manufacture assignment or completion evidence.
